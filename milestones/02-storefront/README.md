# Milestone 2: Build the Storefront

[← Project overview](../../README.md) | [Next milestone →](../03-shopping-and-impact/README.md)

## Goal

Build the pages customers see when they visit Stellafy.

## Your tasks

- Sketch a simple homepage in Figma or on paper.
- Create a shared layout (`base.html`) and a homepage (`index.html`) in `app/templates/`. Put routes in `app/routes/main.py` as you organize the application.
- Add navigation, a short introduction, and six sample products with names, prices and images you have permission to use.
- Store the sample product information in a Python list of dictionaries and display it using a Jinja loop.
- Display three causes: education, environment and community development.
- Style the pages with Tailwind CSS (or plain CSS if you are stuck). Try a narrow browser window as well as a desktop view.

## Before you move on

The homepage loads, six products and three causes are visible, and the layout works on a small screen. You can explain how Python sends product data to your HTML template.

## Submit your work

Attach a screenshot of the storefront and your sketch or Figma link.

Follow the [development workflow](../../README.md#development-workflow): move the Jira task to In Progress, create a branch from your fork's main, commit and push your changes, and open a pull request against your fork's main for mentor review. Link the issue and Jira task. Move the task to Done after approval and merge.
