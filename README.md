# Stellafy — Guided Student Project

**Small purchases. Brighter futures.**

Build a small social-impact commerce prototype. A shopper browses products, selects a cause, simulates a purchase and sees how a merchant commission could support that cause. Analyze fictional transactions to understand the business model. No real payments or donations.

## Learning goals
Learn Python, Flask, HTML, CSS, HTMX, relational databases, financial calculations, data visualization, testing and Git. Build incrementally; understand and explain every change. AI can explain concepts and review your code, but should not complete the project for you.

Fork this repository into your own account, clone your fork and make a meaningful commit after every milestone. Rename your fork to stellafy if desired.
