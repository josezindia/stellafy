# Milestone 1 — Setup

Goal: get the starter running and understand what you are building. Follow [Getting started](../../GETTING_STARTED.md). Write in your own words: who uses Stellafy, what problem it solves, how commissions fund contributions, and what is outside scope. Trace `run.py`, `create_app`, the main route and the index template. Change the welcome page yourself.

Before moving on: browser displays your personalized homepage, starter test passes, README explains the business model. Commit and push.

If stuck: record the exact error, ask for an explanation, and change one thing at a time.
