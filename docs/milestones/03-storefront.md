# Milestone 3 — Storefront

Build a responsive homepage, navigation, featured products and causes. Create at least six fictional product records in Python with name, price in cents, category, description and image. Render them using Jinja loops, not six duplicated HTML blocks. Use plain CSS initially; try Tailwind if helpful. Add a catalogue route and reusable product-card partial. Include accessible image alternatives.

Before moving on: six dynamic products, navigation works, and the page fits a phone screen. Commit and push. If styling takes too long, defer it until the core flow works.
