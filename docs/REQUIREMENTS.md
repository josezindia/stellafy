# Requirements and business model

A customer buys fictional products and chooses a cause (education, environment or community). The simulated merchant commission funds the contribution, not an extra customer charge. Example: $100 sale × 10% commission = $10; 60% allocated to a cause = $6; retained platform revenue before expenses = $4. Sales volume is not revenue; revenue is not profit. Rates are illustrative.

## Required MVP
- Six fictional products with name, price, category, description and image (use owned or licensed images).
- Add/remove products, change quantities and calculate total.
- Three selectable causes and a transparent contribution breakdown.
- Simulated checkout saving order, line items and contribution together; no payment details or real personal information.
- Dashboard with sales, order count, commission, contribution, retained revenue, average order value and two charts.
- Tests, README, reproducible fictional data and a hosted demo if feasible.

## Optional stretch
Search/filter, adjustable rates, CSV export, authentication, Shopify test-store integration. Never process actual money in this student prototype. If behind schedule, finish the cart and impact calculator first; report other features as pending.
